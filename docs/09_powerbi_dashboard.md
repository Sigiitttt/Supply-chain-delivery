# 09 — Power BI Dashboard

## Dashboard 1 — Executive Overview
KPI cards:
- Total Orders
- Delivered Orders
- On-Time Delivery Rate
- Late Delivery Rate
- Avg Delivery Days
- Avg Delay Days

Visual:
- Monthly delivery trend
- On-time vs late
- Top problem states

## Dashboard 2 — Operational Performance
Visual:
- Seller performance matrix
- Customer state map/bar chart
- Seller state performance
- Delivery delay distribution
- Freight vs delivery performance

## Dashboard 3 — Customer Impact
Visual:
- Review score vs delay category
- Review score by delivery status
- Late rate by order value/freight band

## Dashboard Design Rule
Setiap visual harus menjawab satu pertanyaan bisnis. Hindari dashboard yang hanya penuh grafik tetapi tidak membantu keputusan.

## Recommended Filters
- Date
- Customer State
- Seller State
- Order Status
- Product Category
- Seller

## Executive Story
Urutan pembacaan dashboard:
```text
What happened?
      ↓
Where did it happen?
      ↓
Which segment is affected?
      ↓
What operational action should be taken?
```
